# Data Analyst Job Market Analysis

## Project Overview
This project analyzes Data Analyst job listings using Microsoft Excel. The goal was to clean raw job listing data, organize it into a structured format, and identify trends in job titles, salaries, and locations.

---

## Dataset Description
The dataset contains job listings for Data Analyst roles, including job title, company name, location, salary estimates, and additional company information.

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts

---

## Data Cleaning Steps
- Removed duplicates
- Standardized job titles into categories (Data Analyst, Senior, Junior, etc.)
- Cleaned company names (removed ratings from names)
- Standardized location formats
- Converted salary ranges into numeric midpoint values

---

## Analysis Performed
- Counted job listings by job title
- Identified top job locations
- Calculated average salary
- Created summary statistics

---

## Charts Created
- Job Listings by Title (Bar Chart)
- Top Locations by Job Count (Bar Chart)

---

## Key Insights
- Over 60% of listings are general “Data Analyst” roles
- Senior Data Analyst roles represent a significant share of demand
- Job opportunities are highly concentrated in major cities, especially New York
- The average salary across listings is approximately $72K
